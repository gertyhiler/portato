# Triage Labels

| Canonical role | Repository label | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Evaluate scope and evidence |
| needs-info | needs-info | Missing information |
| ready-for-agent | ready-for-agent | Specified enough for implementation |
| ready-for-human | ready-for-human | Human decision, implementation or review |
| wontfix | wontfix | Explicitly declined |

These are readiness labels, not a second lifecycle. GitHub open/closed remains
independent. This local setup documents the vocabulary; remote labels have not
been created. Never infer human acceptance from green tests or a merged PR.
